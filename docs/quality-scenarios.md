# Сценарії атрибутів якості (Quality Attribute Scenarios — ЛР 1)

1. **Продуктивність:** p95 часу збереження транзакції (POST /api/v1/expenses) не перевищує 500 мс при 100 одночасних користувачах.
2. **Надійність:** при збої мережі між бекендом і БД спрацьовує декоратор `@retry(times=3)`; не менше 99% запитів успішно відновлюються.
3. **Безпека (автентифікація):** 100% запитів без валідного JWT або без підпису Telegram відхиляються з кодом 401.
4. **Безпека (ізоляція даних):** механізм Row Level Security (RLS) гарантує 0% доступу до чужих транзакцій.
5. **Підтримуваність:** додавання нового способу оплати або каналу сповіщень займає не більше 4 годин і зачіпає не більше 2 файлів.
6. **Переносимість:** запуск системи на чистій машині в Docker або локально за інструкцією з README.

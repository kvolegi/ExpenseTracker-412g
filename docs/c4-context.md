# Діаграма контексту системи (C4 Context Diagram - Level 1)

## Зовнішні взаємодії:
1. **Користувач:** взаємодіє через Telegram Mini App (Web UI) або бота.
2. **Telegram Bot API:** обробка команд, отримання `initData` авторизації, фонові сповіщення.
3. **Supabase (PostgreSQL 16):** зовнішнє реляційне сховище з механізмом RLS.
4. **Bank API (Monobank/Privat24):** імпорт виписок (перспективне розширення).
5. **Email Service:** резервний канал сповіщень.

# Глосарій предметної області та Зацікавлені сторони (ЛР 1)

## Глосарій (15 ключових термінів)
1. **Користувач** — особа, яка веде облік фінансів у Telegram Mini App.
2. **Telegram ID** — унікальний числовий ID акаунта для входу без пароля.
3. **Telegram Mini App** — веб-застосунок усередині Telegram (Telegram WebApp SDK).
4. **Транзакція** — запис про дохід або витрату (сума, дата, категорія, коментар, тип оплати).
5. **Баланс** — різниця між доходами і витратами (`calculate_balance`).
6. **Категорія** — група транзакцій (Food, Transport, Salary тощо).
7. **Тег** — додаткова позначка транзакції (M:N зв'язок через `expense_tags`).
8. **Бюджет** — ліміт витрат на період.
9. **Тип оплати** — спосіб платежу (cash, card, crypto).
10. **Сповіщення** — фонове повідомлення про транзакцію в Telegram.
11. **Статистика** — аналітичні зведені дані доходів і витрат за період.
12. **JWT-токен** — підписаний токен для авторизації API-запитів.
13. **Row Level Security (RLS)** — механізм PostgreSQL для ізоляції даних між користувачами.
14. **Фонове завдання** — асинхронна фонова задача (`BackgroundTasks` у FastAPI).
15. **Репозиторій** — шар доступу до даних (`src/repositories/`).

## Перелік зацікавлених сторін (Stakeholders)
- **Користувач:** швидкий запис витрат, безпека даних.
- **Команда розробників (3 особи):** простота супроводу та модульність.
- **Викладач (замовник):** обґрунтовані рішення, повна архітектурна документація.
- **Telegram (платформа):** сумісність із правилами Mini App.
- **Supabase (БД):** економія запитів у безкоштовному тарифі, робота RLS.
- **Особа, що розгортає:** простий запуск локально або в Docker.

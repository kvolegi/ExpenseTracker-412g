## Аудит реалізації сценаріїв якості з ЛР1:
1. **Продуктивність (Latency):**
   * Ендпоінти FastAPI перевірено через Swagger UI (`/docs`).
   * Запити створення транзакції виконуються асинхронно.
2. **Безпека (Security):**
   * Роутери захищені перевіркою JWT-токена (`get_current_user`).
   * Невалідні або відсутні токени повертають статус 401 Unauthorized.
3. **Підтримуваність (Maintainability):**
   * Багатошарова структура ядра (Presentation, Application, Domain, Infrastructure) чітко розмежовує відповідальність.

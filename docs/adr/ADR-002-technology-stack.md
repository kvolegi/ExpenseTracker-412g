# ADR-002. Вибір технологічного стека

**Статус:** Прийнято  
**Дата:** 2026-10-05  
**Автори:** Петрушенко М.Р., Чугунникова В.І., Бевзюк Є.С.  

## Контекст
Після вибору модульного моноліту (ADR-001) потрібно зафіксувати стек технологій. Стек має бути знайомий усім учасникам команди настільки, щоб на ньому можна було реалізувати наступні лабораторні роботи.

## Рішення
1. **Серверна частина:** Python 3.12, FastAPI 0.111 (автодокументація Swagger UI, валідація схем через Pydantic v2, асинхронні фонові задачі).
2. **База даних:** Supabase (PostgreSQL 16) з підтримкою Row Level Security (RLS) без ручного адміністрування серверів.
3. **Інтерфейс:** Vanilla JS + Telegram WebApp SDK в одному легкому файлі `index.html` (швидкий старт, без зайвого оверхеду збірки).
4. **Розгортання:** Docker 25, локальний запуск або Railway.app.

## Наслідки
Швидкий запуск, готова документація API (`/docs`), мінімальний оверхед на збірку.
